איך המחשב שלך מדבר עם העולם? 🌐

כדי לגלוש באינטרנט, לשחק אונליין או לשלוח הודעה – המחשב שלך חייב "תעודת זהות" רשתית. בשיעור הזה נהפוך לחוקרי סייבר: נלמד לפתוח את מסוף המחשב (CMD), נאתר את **כרטיס הרשת** הפיזי, ונחשוף את כתובת ה-IP של **הראוטר בבית (Default Gateway)**!

1

פענוח המושגים: ארבעת המופלאים

Physical Address

1. כתובת MAC (כרטיס הרשת)

זהו "מספר תעודת הזהות" הפיזי של כרטיס הרשת שלך. הוא נצרב במפעל ולא משתנה לעולם! נראה כך: 00-1A-2B-3C-4D-5E.

IPv4 Address

2. כתובת IP (הכתובת שלך ברשת)

הכתובת הלוגית של המחשב בתוך הרשת הביתית. הראוטר מחלק אותה באופן אוטומטי (DHCP). נראית כך: 192.168.1.15.

Subnet Mask

3. מסכת רשת (Subnet Mask)

הקוד שמפריד בין "שם השכונה" ל"מספר הבית". ברוב הרשתות הביתיות היא תהיה: 255.255.255.0.

Default Gateway

4. שער ברירת המחדל (הראוטר!)

**שער היציאה לאינטרנט.** זוהי הכתובת הפנימית של הראוטר הביתי שלך. כל חבילת מידע שרוצה לצאת החוצה עוברת דרכו! למשל: 192.168.1.1.

2

המעבדה: שלוף את נתוני הרשת שלך!

הוראות ביצוע צעד-אחר-צעד:

  1. לחץ במקלדת על מקש Windows + R (או חפש CMD בשורת החיפוש).
  2. בחלונית שנפתחה הקלד cmd ולחץ Enter.
  3. בחלון השחור שנפתח, הקלד את הפקודה הבאה ולחץ Enter:
Command Prompt
C:\Users\Student> ipconfig /all
מה מוארים עכשיו בחלון השחור?

חפש את כרטיס הרשת הפעיל שלך (בדרך כלל נקרא Wireless LAN adapter Wi-Fi אם אתה באלחוטי, או Ethernet adapter אם אתה מחובר בכבל):

  • Physical Address: זוהי כתובת ה-MAC של הכרטיס.
  • IPv4 Address: כתובת ה-IP האישית של המחשב שלך.
  • Default Gateway: 💥 הנה הראוטר שלך! רשום את הכתובת הזו בצד.
